# CLAUDE.md — Ludo Arena Flutter app

The Flutter version of the Ludo FYP app. It mirrors the React Native app in [../mobile](../mobile) screen for screen and uses the same backend ([../backend](../backend), API + socket events in [../CLAUDE.md](../CLAUDE.md) §8–§9).
The user runs it **on another PC**. On this PC, run only `flutter pub get`, `flutter analyze` and `flutter test` (the user approved these). Don't `flutter run` or build here unless asked.

## Rules
1. **Readable code first** (FYP viva): one screen = one file, a 1–2 line comment at the top of every file, comments on the *why*.
2. Keep it the **same app as the React Native one**: when a feature changes in one app, change it in the other too.
3. **The server decides the game.** The app only sends `game:roll` / `game:move` and draws what the server sends.
4. Colours, gradients and text styles live in `lib/theme.dart`.
5. REST calls go through `lib/api/endpoints.dart` (one static method per endpoint). Socket acks go through `SocketService.instance.emitAck()`, and listening goes through `SocketService.instance.on(event, handler)`, which returns an unsubscribe function to call in `dispose()`.
6. Keep `flutter analyze` at **0 issues** and `flutter test` green.

## Notes
- Navigation is plain `Navigator` + `MaterialPageRoute`. `Notifications.instance.navigatorKey` lets alerts open screens. Tabs switch with `MainTabs.selectedTab.value = i`.
- Screens reload their data when you come back to them: `with RefreshOnReturn` → `onReturn()`. Tabs reload when selected (a listener on `MainTabs.selectedTab`).
- After login / register, call `Navigator.popUntil((r) => r.isFirst)`, because `RootGate` swaps the welcome screen for the tabs underneath.
- Game-state models (`MatchInfo`, `Seat`, `Token`) are mutable. The game screen changes them from socket events and calls `setState`.
- Every match event carries `match_id`. `GameScreen._listen` ignores other matches. Send `match:leave` in `dispose()`.
- `android/` is generated by `setup.ps1` on the other PC, so it isn't kept in this folder.
